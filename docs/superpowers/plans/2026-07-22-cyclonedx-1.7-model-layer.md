# CycloneDX 1.7 + Model (IR) Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add opt-in CycloneDX 1.7 output to cbom-lens behind a per-version Emitter, with a lens IR that isolates business logic from the wire format.

**Architecture:** Three sequential tickets. **Ticket 0** makes current 1.6 output deterministic so a byte-identical golden gate is possible. **Ticket 1** introduces the `internal/model/cbom` IR + `Emitter` interface + `emit16`, moving all version-sensitive field writes/read-backs into the IR — output stays byte-identical to the Ticket 0 golden. **Ticket 2** bumps `cyclonedx-go` to v0.11.0 and adds `emit17` + the 1.7 schema, opt-in via config.

**Tech Stack:** Go, `github.com/CycloneDX/cyclonedx-go`, `github.com/stretchr/testify/require`, `github.com/kaptinlin/jsonschema` (validation), `github.com/google/uuid`.

**Spec:** `docs/superpowers/specs/2026-07-22-cyclonedx-1.7-model-layer-design.md`

```go
func TestBuilder_StableOrdering(t *testing.T) {
	newB := func() *Builder {
		b, err := NewBuilder(model.CBOM{Version: "1.6"})
		require.NoError(t, err)
		// two components + one dependency; map iteration order is randomized per range
		b.components["b@2"] = &cdx.Component{BOMRef: "b@2", Name: "b"}
		b.components["a@1"] = &cdx.Component{BOMRef: "a@1", Name: "a"}
		deps := []string{"a@1"}
		b.dependencies["b@2"] = &deps
		return b
	}
	first := newB().BOM(context.Background())
	for i := 0; i < 20; i++ {
		got := newB().BOM(context.Background())
		require.Equal(t, *first.Components, *got.Components, "components order must be stable")
		require.Equal(t, *first.Dependencies, *got.Dependencies, "dependencies order must be stable")
	}
	// and it is sorted ascending by ref
	refs := []string{(*first.Components)[0].BOMRef, (*first.Components)[1].BOMRef}
	require.True(t, sort.StringsAreSorted(refs), "components sorted by BOMRef")
}
```

- [ ] **Step 2: Run test to verify it fails**

Run: `go test ./internal/bom/ -run TestBuilder_StableOrdering -v`
Expected: FAIL intermittently (order differs across the 20 iterations).

- [ ] **Step 3: Implement**

In `BOM()`, after the `components`/`dependencies` slices are populated (after the two `for` loops, before constructing `cdx.BOM`), sort them by their final wire ref:
```go
	slices.SortFunc(components, func(a, b cdx.Component) int {
		return strings.Compare(a.BOMRef, b.BOMRef)
	})
	slices.SortFunc(dependencies, func(a, b cdx.Dependency) int {
		return strings.Compare(a.Ref, b.Ref)
	})
```
(Note: `safeRefs` runs before this and has already rewritten `BOMRef`/`Ref` to their wire values, so sorting here sorts by wire ref. Inner `dependsOn` element order is preserved from the source detection and is already deterministic.)

```go
package cbom

import cdx "github.com/CycloneDX/cyclonedx-go"

type AssetRef string

type KeyMeta struct{ Size string } // RSA→bits "2048"; EC→curve "secp256r1"

type Asset struct {
	Ref       AssetRef
	Component cdx.Component
	Key       *KeyMeta
}

type RelationshipKind string

const (
	RelSignatureAlgorithm RelationshipKind = "signature-algorithm"
	RelSubjectPublicKey   RelationshipKind = "subject-public-key"
	RelMaterialAlgorithm  RelationshipKind = "material-algorithm"
	RelProtocolCrypto     RelationshipKind = "protocol-crypto"
	RelDependsOn          RelationshipKind = "depends-on"
)

type Relationship struct {
	From AssetRef
	To   AssetRef
	Kind RelationshipKind
}

type DetectionType string // move the existing consts from internal/model/detection.go here

type Detection struct {
	Source   string
	Type     DetectionType
	Location string
	Assets   []Asset
	Services []cdx.Service
	Rels     []Relationship
}

// BOMModel is the deduped, ref-canonicalized structure Emitters consume.
type BOMModel struct {
	Assets []Asset           // deduped by Ref, evidence merged
	Rels   []Relationship    // deduped by (From,To,Kind)
	Services []cdx.Service
	SerialNumber string
	Timestamp    string
	StatsProps   []cdx.Property
}
```
